# API reference

The machine-readable contract is `api/openapi/catalog.json` (generated by `dotnet build`) and, for the SPA, `web/src/api/schema.ts`. This page is the human summary. Routes are in three groups ([ADR 0007](../adr/0007-admin-tenant-comes-from-session.md)):

- `/api/public/{tenantSlug}`: anonymous, one Tenant, Published products only.
- `/api/admin`: Admin (Bearer token from Supabase); the Tenant comes from the session.
- `/api/platform`: Platform Admin.

List endpoints take `page` and `pageSize` and answer `{ items, page, pageSize, totalCount }`.

## General

| Method and route | Purpose |
| --- | --- |
| `GET /api/health` | Liveness and database check |
| `GET /api/me` | The signed-in person: user id, email, whether Platform Admin, Tenant id |

## Public

| Method and route | Purpose |
| --- | --- |
| `GET /api/public/{tenantSlug}` | Tenant name, current slug, profile, Logo URL, Brand color, whether Inquiries are on. Accepts an Old slug |
| `GET /api/public/{tenantSlug}/products` | Published products. Query: `q`, `categoryId`, `sort` (`relevance`, `featured`, `name`, `newest`), `featured`, `attr.{definitionId}=value` (repeatable), paging |
| `GET /api/public/{tenantSlug}/products/{productSlug}` | Product detail with Images (original and Thumbnail URLs) and Attributes. Accepts an Old Product slug and returns the current one |
| `GET /api/public/{tenantSlug}/products/{productSlug}/related` | Related products (paged) |
| `POST /api/public/{tenantSlug}/products/{productSlug}/inquiries` | Send an Inquiry `{ name, email, message, website }` (`website` is the honeypot). 202; 404 when Inquiries are off or the product is not Published; 429 |
| `POST /api/public/{tenantSlug}/products/{productSlug}/views` | Record a Product view. 202; 404 when not Published; 429 |
| `GET /api/public/{tenantSlug}/categories` | Category tree (only Categories with Published products), whole |
| `GET /api/public/{tenantSlug}/filters` | Filterable attributes and their Options, whole |
| `GET /api/public/{tenantSlug}/sitemap.xml` | The Tenant's Sitemap (not in OpenAPI); 404 without `PublicSite__BaseUrl` |
| `GET /api/public-sitemap.xml` | Sitemap index of all active Tenants (not in OpenAPI) |

## Admin

| Area | Method and route | Purpose |
| --- | --- | --- |
| Tenant | `GET /api/admin/tenant` | Current Tenant id, name, slug |
| Profile | `GET`, `PUT /api/admin/tenant/profile` | Read and update the profile and `inquiriesEnabled` |
| Logo | `PUT`, `DELETE /api/admin/tenant/logo` | Upload (multipart `file`) or remove the Logo |
| Dashboard | `GET /api/admin/dashboard` | Counts: `draftCount`, `publishedCount`, `archivedCount`, `featuredCount`, `openInquiryCount`, `publishedWithoutImagesCount`, `publishedWithoutCategoriesCount`, `hasCategories` |
| Statistics | `GET /api/admin/stats/products` | Views and Inquiries per product. Query `from`, `to`, paging |
| Team | `GET`, `POST /api/admin/admins`, `DELETE /api/admin/admins/{id}` | List, invite, remove Admins |
| Attributes | `GET`, `POST /api/admin/attribute-definitions` | List (paged), create |
| | `PUT`, `DELETE /api/admin/attribute-definitions/{id}` | Update name and filterable; delete (`confirm=true` when used) |
| | `POST /api/admin/attribute-definitions/{id}/options` | Add an Option |
| | `DELETE /api/admin/attribute-definitions/{id}/options/{optionId}` | Delete an Option (`confirm=true` when used) |
| Categories | `GET`, `POST /api/admin/categories` | Tree (whole), create |
| | `PUT`, `DELETE /api/admin/categories/{id}`; `POST .../{id}/move` | Rename, delete, move `{ parentId, position }` |
| Products | `GET`, `POST /api/admin/products` | List (filters: `q`, `status`, `categoryId`, `featured`, `hasImages`, `hasCategories`), create |
| | `GET`, `PUT /api/admin/products/{id}` | Read, update name, SKU, description, slug |
| | `POST .../{id}/status` | Change status `{ status }` |
| | `PUT .../{id}/featured` | `{ featured }` |
| | `PUT .../{id}/attributes`, `PUT .../{id}/categories` | Replace Attribute values / Categories |
| | `POST .../{id}/duplicate` | Duplicate as a Draft |
| | `POST .../{id}/images`, `PUT .../{id}/images/order`, `DELETE .../{id}/images/{imageId}` | Upload, reorder, delete Images |
| | `POST /api/admin/products/bulk` | Bulk action `{ productIds, action, categoryId? }` → `{ succeeded, failed }` |
| | `GET /api/admin/products/export`, `POST .../import?dryRun=` | CSV export and import |
| Inquiries | `GET /api/admin/inquiries` | Inbox (paged, `status` filter, newest first) |
| | `PUT .../{id}/status`, `DELETE .../{id}` | Open/Handled, delete |

## Platform

| Method and route | Purpose |
| --- | --- |
| `GET`, `POST /api/platform/tenants` | List (paged) and create Tenants |
| `POST /api/platform/tenants/{id}/deactivate`, `.../reactivate` | Suspend and restore |
| `PUT /api/platform/tenants/{id}/slug` | Change the Tenant slug (previous one becomes an Old slug) |
| `GET`, `POST /api/platform/tenants/{id}/admins` | List and invite Admins of a Tenant |

Error codes and limits: [Rules and limits](./rules-and-limits.md).
